The installation enables *Enforce Cities* on Thailand (*Contacts >
Configuration > Localization > Countries*). Disable it to type the City
instead of selecting the sub-district and district.

To change the layout of the street lines, activate the developer mode and
edit *Thai Street Format* on *Thailand*. Line 1 is Street, line 2 is
Street 2. Default:

    %(l10n_th_house_number)s %(l10n_th_moo)s %(l10n_th_village)s %(l10n_th_building)s %(l10n_th_floor)s %(l10n_th_room)s
    %(l10n_th_soi)s %(l10n_th_yaek)s %(l10n_th_road)s
